# SYMBOL — Interior Studio

Веб-редактор дизайн-проекта квартиры по исходным чертежам ЖК «Символ».

## Запуск

Откройте `index.html` в современном браузере. Это статическое приложение без сборки и внешних зависимостей.

## Возможности текущей версии

- 8 помещений с площадями из экспликации исходного PDF;
- выбор помещения и интерактивная схема;
- настройки пола, стен и освещения;
- локальное сохранение настроек и экспорт проекта в JSON;
- адаптивный интерфейс.

## Точность данных

Экспликация указывает 118,60 м², а общие данные чертежа — 120,0 м² после монтажных работ. Значения сохранены как в исходном документе. Геометрия зон на схеме ориентировочная и не является CAD/BIM-моделью или основанием для строительных работ.

## Публикация

GitHub Actions автоматически публикует приложение в GitHub Pages при обновлении ветки `main`. Адрес после успешного развёртывания: https://vyihawk.github.io/Symbol/
